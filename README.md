# Make the Coolest Art — coolest-art-01

This program copies the original artwork “Dandelion Planet” — a giant glowing dandelion seed-head floating like a golden planet in deep indigo space, with a tiny astronaut standing on one seed — to `/output/entry.png`.

Run locally with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
